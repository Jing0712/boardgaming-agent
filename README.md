# 小懵 · AI 桌游主持人

一个基于大语言模型的 AI 桌游主持人，帮助玩家快速上手新桌游：讲规则、指导摆放、逐回合主持、记录分数、协助结算。

角色"小懵"有点小迷糊，但对规则很认真——不确定的地方会明确说出来，不会编造规则。

## 功能

- 分阶段主持：识别游戏 → 30 秒介绍 → 摆放指导 → 开局教学 → 逐回合主持 → 规则问答 → 状态记录 → 结算
- 支持上传图片（规则书页面、桌面摆放、卡牌等），模型可结合图片回答
- 回复精简、可扫读，避免长段落
- 角色有多种表情状态（待机 / 思考 / 说话 / 出错），根据对话状态实时切换
- 单文件 HTML + 少量图片素材，无需构建工具，本地打开即可用

## 使用方法

1. 克隆或下载本仓库
2. 用浏览器直接打开 `index.html`
3. 点击右上角 ⚙ 设置，填入你的火山方舟（Volcengine Ark）API Key 和推理接入点 ID
4. 保存后即可开始对话

### 关于 API Key

API Key 只保存在你本地浏览器（打开 index.html 的那个标签页）中，直接从浏览器发送到火山方舟接口，不经过任何第三方服务器。勾选"记住这台设备"会把 Key 存进浏览器的 localStorage，同样只留在本机。

**不要**把写有你自己 Key 的文件提交到公开仓库或分享给他人。

### 已知限制

- 目前通过浏览器直接调用 Volcengine Ark API，可能会遇到 CORS（跨域）限制导致请求失败。如果遇到 `Failed to fetch` 错误，通常需要搭建一个简单的服务端代理来转发请求。
- 未做移动端专项适配，建议先在桌面浏览器测试。
- 模型的规则解释仅供参考，正式比赛或有争议场景请以官方规则书为准。

## 技术说明

- 纯前端实现，无后端、无构建步骤
- 通过 OpenAI 兼容格式调用 Volcengine Ark 的 `/chat/completions` 接口
- 角色表情通过图片交叉淡入淡出（crossfade）实现动画效果
- 系统提示词内置在 `index.html` 中的 `SYSTEM_PROMPT` 常量里，可直接编辑调整主持人的语气、格式和行为规则
