# 游戏规则文本（可选，按需添加）

这个目录让 AI 主持人在玩某款游戏时，能引用真实规则文本回答问题，而不是完全凭模型的记忆编——对规则很细的重策略游戏（伯明翰、大西部之路这类）效果最明显。

没有对应文件的游戏完全不受影响，照旧走原来的通用主持流程。

## 怎么加一款游戏

1. 把这款游戏的规则整理成一个纯文本文件，放进这个目录，比如 `birmingham.txt`。
2. 在 `manifest.json` 里加一行，把游戏名（要跟玩家开局时输入的名字完全一致）映射到文件名：

```json
{
  "伯明翰": "birmingham.txt"
}
```

3. 完事——下次有人开一局叫这个名字的游戏，这份文本会自动被塞进 AI 的系统提示词里。

## 内容建议

- 不需要整本书一字不差地搬进来，挑"AI 容易凭空编"的部分：具体数值、资源换算、计分规则、结束条件——这些是最容易被瞎编的地方。
- 纯文本就行，不需要排版，AI 自己会理解。
- 文件大小控制在合理范围（几千字比较合适），太长会拖慢每次请求、增加成本。

## 关于版权

这里存的是游戏的规则说明，不是完整复刻出版物本身（图片、美术、排版这些不需要，也不建议放）。规则本身（数值、流程这类事实性信息）版权保护的范围通常比较有限，但具体到你怎么组织这份内容、要不要往这里放官方规则书的大段原文，属于你自己产品要承担的判断和责任，不在这份说明的建议范围内。
